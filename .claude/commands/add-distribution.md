---
description: 確率分布の行を prob.html に追加する
argument-hint: "[分布名] (例: レヴィ分布)"
---

prob.html の「確率変数が連続(Continuous)な確率分布」または「離散(Discrete)」のテーブルに、指定された分布の行を追加してください。

手順（詳細は `add-table-row` スキルに従う）:
1. 既存の行（例: コーシー分布、レヴィ分布）の HTML 構造を参考に、4列構成（表記画像 / LaTeX / 意味 / 例画像）の `<tr>` を作る
2. 表記・数式・グラフの PNG 画像が必要なら `img9/` に matplotlib などで生成する（matplotlib はユーザー環境にインストール済みでそのまま使える。使えない場合は venv を一時的に作り、生成後は用が済んだら明示する）
3. 画像には意味のある `alt` 属性（LaTeX ソースなど）を付ける
4. 説明文は日本語で、分布の別名・英名・性質・利用例・名前の由来を既存行と同じ粒度で書く

分布名: $ARGUMENTS
