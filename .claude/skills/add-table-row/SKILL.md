# テーブル行追加スキル

各ページの記号・分布テーブルに新しい行を追加する。対象は prob.html 以外のどのページでもよい。

## 共通の手順

1. 対象ページを Read で確認し、追加先のテーブルと既存行のマークアップ構造を真似る（行番号は流動的なので、コメント `<!-- 名前 -->` や `<caption>` を目印に探す）
2. 多くのページは4列構成: 表記画像 `<td>` / LaTeX `<small>` / 意味（日本語、`<br />` 区切りの箇条書き）/ 例画像。対象テーブルの実際の列数・構成に合わせる
3. 行の前にコメント `<!-- 項目名 -->` を付ける（既存行の慣習）
4. 画像 `<img>` には LaTeX ソースを `alt` に入れる（既存行の慣習）
5. 説明文は日本語で、既存行と同じ粒度で書く。含める内容は分野に応じて変える（後述）
6. ファイルはインデントがタブ・スペース混在なので、Edit 前に Read で正確な空白を確認する

## 画像の生成と配置

- 出力先は対象ページが使う `img*/`（ページと画像ディレクトリの対応は概ね一対一。例: prob.html → img9/、alg.html → img17/、anal.html → img12/、logic.html → img2/。複数使うページもあるので `grep -o 'src="img[^"]*"' <page>` で確認する）
- `img*/` 内の既存画像は他ページから参照されていることがある。削除・リネームしない
- ファイル名は既存の命名規則（`equation*.png` など）に合わせ、既存ファイルを上書きしない
- matplotlib で生成する:
  - システム Python に matplotlib が無い場合は `python3 -m venv` で一時 venv を作り、用が済んだら明示する
  - 数式画像は `fig.text` + mathtext で透明背景 PNG、グラフは 150dpi 程度

## 説明文の粒度（分野別）

- **確率分布**（prob.html）: 日本語名・英名・別名、定義域、パラメータの意味、尾の重さなどの性質、利用例、名前の由来（数学者名）。離散か連続か・期待値や分散の有無・定義域の端に注意
- **記号・演算**（alg.html, sets.html など）: 記号の読み方・別表記、定義、利用場面、例
- **公式・法則**（ineq.html, elec.html, econ.html など）: 式の意味・成立条件、利用例、名前の由来

## 注意

- 追加先のテーブル（離散/連続、記号の分類など）を間違えない
- 既存ページ `img9/` などへの参照を壊さない（verify-html スキルで検査する）
